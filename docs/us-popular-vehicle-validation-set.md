# 美國熱門車型配對驗證集（2025）

更新日期：2026-10-21

## 用途與方法

此文件定義一組可重複執行的 GasWise 車型配對驗證集。範圍是 2025 曆年（目前最新的完整年度）美國新輕型車銷量最高的 10 個**品牌**，每品牌取美國銷量最高的 5 個 nameplate，共 50 組。輕型車包含乘用車、SUV、pickup 與 van；這是美國業界年度銷售報告常用口徑，不代表道路保有量。

品牌排名以各車廠公布資料彙整表交叉核對；2025 前十依序為 Toyota、Ford、Chevrolet、Honda、Hyundai、Nissan、Kia、GMC、Subaru、Jeep。[品牌排名與銷量彙整](https://www.best-selling-cars.com/usa/2025-full-year-usa-top-light-vehicle-and-car-manufacturers-and-brands/)

證據優先順序：

1. 車廠官方美國年終銷售表、官方 newsroom 或向 SEC 提交的附件。
2. 車廠透過 PR Newswire 發布的年終表。
3. 若官方網頁只公布摘要或附件不易直接解析，使用 Automotive News／專業銷售資料站轉錄的官方表，並明確標記為「次級轉錄」。

「熱門」只用 2025 全年銷量排序，不以評論、搜尋熱度或主觀推薦決定。油電、PHEV、EV 若由原廠併入同一 nameplate，測試時也視為同一 model family；配對引擎仍必須再利用年份、trim、drive、fuel type 等欄位選到正確 EPA 車輛，不可只憑 nameplate 猜定單一油耗。

## 預期的配對驗證規則

每一列至少應驗證以下行為，而不是只驗證搜尋有結果：

1. 品牌與 nameplate 能找到候選車型，且第一頁候選不混入其他品牌。
2. 輸入常見標點與空白變體仍能配對，例如 `F-150`、`F150`、`F Series`，`CR-V`、`CRV`，`HR-V`、`HRV`。
3. 年份必須限制 EPA 候選；不得把同名但不同世代的油耗直接套用。
4. 汽油、diesel、hybrid、PHEV、EV 必須分開。純 EV 沒有 MPG 時，不能偽造 MPG；若產品只支援液體燃料，應清楚回報不適用。
5. AWD/4WD/2WD、引擎排量、汽缸數或 transmission 有多個候選時，系統應要求確認，或回傳估算範圍與低信心，不得靜默任選。
6. 系統保存 EPA vehicle ID、model year、make、model、trim、drive、fuel type 與來源，不只保存顯示文字。
7. alias 只能改善召回率，不能消除差異：`K4/Forte`、`Bronco/Bronco Sport`、`Equinox/Equinox EV`、`Yukon/Yukon XL`、`Wagoneer/Grand Wagoneer` 都是特別的反誤配案例。

## 已知限制

- 這是「2025 新車銷量」驗證集，不是全美道路存量。若目標是覆蓋現役車齡，還應再加入 5、10、15 年前的熱門世代與已停產 nameplate。
- 品牌總量排名的彙整站明示其數字來自各車廠，但不同車廠對 sales、deliveries、fleet 的定義可能不同；這不影響同一品牌內挑選五個測試 nameplate，但不適合拿來做精細市場占有率推論。
- GM 官方提供可下載的 deliveries 附件，主新聞頁沒有完整 HTML model table；Chevrolet/GMC 的排序以該官方附件為準。
- Hyundai 年終新聞稿可證實年度紀錄與主要熱門車型，但易讀的完整排序採 Automotive News 對原廠表的轉錄交叉核對。
- Jeep 應以 Stellantis/FCA 年終附件為準；若 CI 無法取得官方頁面，次級轉錄只可作測試資料快照，不能標為官方 API。
- `F-Series` 是系列彙總，不是單一 EPA model；實際匹配必須拆成 F-150、F-150 Lightning、F-250/350 等。Transit 也必須區分動力與車身配置。
- 2025 Ford Transit 不在 EPA/DOE 輕型車油耗目錄中；驗收預期是明確回報不可用，不得配成其他 Ford 車型或捏造 MPG。
- 年度銷售排名不等於資料庫支援正確。真正驗收需針對這 50 組逐一檢查候選、年份、動力、EPA ID 與 MPG/MPGe 單位。

## 建議的機器可讀 fixture 欄位

後續若把本表轉為自動測試，fixture 至少應包含：

```text
brand_rank, make, model_rank, query_aliases, canonical_nameplate,
model_years_to_sample, expected_fuel_types, must_not_match,
sales_source_url, source_tier
```

建議每個 nameplate 抽三個年份（最新、約五年前、約十年前）；50 個 nameplate 最少形成 150 個年份層級案例，再針對多動力與 AWD/2WD 車型展開 variant 測試。

## 2026-10-22 即時驗證結果

以 `backend` 目錄執行：

```bash
uv run python ../scripts/smoke/check_popular_vehicle_catalog.py
```

結果為 60/60 符合預期：59 組解析到年份、品牌、EPA model、EPA vehicle ID、燃料種類與正值 combined MPG；2025 Ford Transit 依預期回報目錄不可用。測試工具只為驗證而遍歷配置選項，產品 UI 仍會要求使用者確認車身、驅動、引擎或變速箱，不會把驗證工具挑到的代表配置當成使用者的車。

這輪發現並修復：

- 前綴誤配會把 Corolla Cross、Bronco Sport、Wagoneer S 混進不同 nameplate。
- EV／PHEV／FCEV 候選可能進入液體燃料流程，最後才丟出 provider error；現在已先排除可辨識標籤，剩餘不支援記錄會回傳清楚的 `no_match`。
- 市場系列名稱 `F-Series`、BMW `3 Series`／`4 Series`、Mercedes-Benz `G-Class` 與 EPA model 命名不同；現在只展開成受限的系列候選，仍保留配置確認。
