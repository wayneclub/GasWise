# Price cache, freshness and discovery

Implemented 2026-10-12. Research reference: [RFC 5861](https://www.rfc-editor.org/rfc/rfc5861), particularly visible stale content, bounded revalidation, and avoiding amplification. GasWise keeps the current screen while a new request runs; it does not silently extend expired source prices after an error.

- Smart acquisition caches each provider query in bounded process memory for 90 seconds. Source ID, exact location, radius, fuel, detail budget and search text participate in the key. Keys are hashed; no disk history or persistent location store. Maps discovery uses stable shared viewport cells with 10% extra radius; results are filtered against the user’s exact original radius. Route endpoints remain exact. Cache entries are deep-copied so tagging, merging or ranking cannot contaminate another search.
- Identical in-flight reads are coalesced. Shared reads survive cancellation by one of several callers. Provider errors have a 30-second cooldown, remain explicitly unavailable, and are never cached as successful price data. Manual refresh bypasses per-query failure cooldown, but a provider-wide rate-limit cooldown still protects queued requests. Successful source results can be reused while another source is unavailable, with the unavailable status shown separately.
- Routes use their own exact origin/destination/via key and expire after 300 seconds. Payment and gallons do not alter a route. Both payment bases are considered during route acquisition, and all originally collected payment variants remain in the signed snapshot.
- Manual refresh bypasses price reuse. Cash/card/gallons/rewards changes call rerank with zero price/route upstream calls. Automatic refresh happens every 120 seconds only while the fuel view is mounted, visible and online. Hidden tabs pause; returning after the interval triggers an update. Errors retain the displayed snapshot with an explicit error and back off to 240, 480, then at most 600 seconds.
- Cache reuse never rewrites `price_updated_at` or `fetched_at`. Ranking recomputes quote age at request time, excludes selected quotes older than 24 hours, preserves unknown timestamp/payment labels and original raw prices, and never treats a cache hit as a new source report. Retrieval, quote age, source and estimated credit adjustment are distinct.
- Results expose `cache_hits`; upstream counters omit hits. `gasbuddy_pages` records actual GraphQL page reads, separate from the high-level source-search count. No distributed cache/database is currently necessary for the single-process deployment. For multiple workers, shared provider cache and a distributed lock would be needed; use a separate cache service rather than persisting users' exact locations in PostgreSQL.

## C.T. Truck Stop investigation

GasBuddy station [35593](https://www.gasbuddy.com/station/35593), 1400 S Alameda St, Los Angeles CA 90021-2426, did not appear in the first GPS search page. Bounded pagination (three pages) returned Premium cash $6.17 and credit $6.37, posted 2026-10-12T10:52:04Z. The ordinary Maps viewports omitted this address. A targeted gas-station/address query recovered Google place `ChIJWZQfubPJwoARPi1Ncuu4EKE`, named Shell, with matching full street/city/state/ZIP and coordinates. Native Maps marks it permanently closed; observed field 23 = 1 confirms this even when its hours field 203 is absent. Native Maps also lists differently named nearby businesses; their status must not be copied onto the old Shell.

Default source requests remain one page / zero targeted lookups for API compatibility. The frontend first requests one GasBuddy page to reduce cold-search latency and at most five targeted address lookups for unmatched, dated, usable quotes, prioritizing known nearby ZIPs. Once that result is visible, a non-blocking search restores the prior three-page Regular or five-page non-Regular coverage and replaces the snapshot only on success. Batch collection independently keeps its eight-page limit. All requests remain bounded, and provider failures leave the one-page result visible. Remaining pagination/coverage limitations remain visible rather than claiming every station was found.

The recovered C.T. quotes are discoverable under **Not recommended**, showing both payment prices, GasBuddy source/age and the conflicting Google Shell closure evidence. They are excluded from navigation and recommendation under the existing require-open rule. Unmapped quotes are also visible there without invented coordinates. Source disagreement means current operation/price cannot be guaranteed; do not label the screenshot or a recent report as pump-level verification.

## Live verification

At 17:02 UTC (10:02 Los Angeles), a bounded local search returned the two C.T. quotes with the closure exclusion. Repeating the same search immediately produced 13 cache hits and **zero** upstream calls, retaining identical source quote and fetch timestamps. This confirms normal source reuse without manufacturing freshness. AWS previously returned GasBuddy's `gasbuddy_http_bootstrap_challenge`; pagination cannot bypass that upstream refusal. The UI now explicitly lists unavailable sources, and deployment verification must distinguish local GasBuddy success from AWS provider access.
